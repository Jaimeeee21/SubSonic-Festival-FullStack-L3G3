## ⚙️ IMPORTANTE: Puesta en marcha de la web y Configuración

Sigue estos pasos para poner en marcha el entorno de desarrollo:
 1.- Añadir las credenciales de la Base de Datos a la carpeta del proyecto (Se ha mandado el .json junto con la entrega)
 2.- En la carpeta raíz del proyecto ejecutar: > pip install -r requirements.txt  Para descargar dependencias.
 3.- Tras eso, ejecutar > python run.py
 4.- Abrir el navegador con "localhost:8000"

## 📊 Para abrir la página web en modo administrador/gestor:

 1.- Tras hacer todo lo demás, abrir el enlace: "localhost:8000/admin.html"
 3.- El usuario y contraseña son:
